Politique de confidentialité

Dernière mise à jour : Avril 2026

Noki Noki est une application mobile permettant de publier et consulter des annonces et services locaux. Nous attachons de l’importance à la protection de vos données et à la transparence sur leur utilisation.

1. Données utilisées

Dans cette version de Noki Noki, aucune création de compte utilisateur n’est requise. L’application peut utiliser les données suivantes :

  • Les annonces que vous publiez
  • Le numéro WhatsApp que vous choisissez d’afficher dans une annonce
  • La ville et le pays sélectionnés
  • Les statistiques locales d’activité, comme les vues et les contacts
  • Les avis que vous laissez
  • Les signalements que vous effectuez
  • Les informations liées aux boosts gratuits

2. Visibilité des informations

Lorsque vous publiez une annonce, les informations de cette annonce peuvent être visibles par les autres utilisateurs de l’application. Le numéro WhatsApp renseigné est utilisé pour permettre aux personnes intéressées de vous contacter.

3. Stockage des données

Les données de cette version sont principalement stockées localement sur votre appareil. Noki Noki ne propose pas encore de compte utilisateur ni de synchronisation serveur.

4. Utilisation des données

Les données sont utilisées pour faire fonctionner l’application : afficher les annonces, permettre le contact via WhatsApp, enregistrer les statistiques locales, gérer les avis, les signalements et les boosts gratuits.

5. Signalements et support

Les signalements sont enregistrés localement dans l’application. Si vous contactez le support, les informations que vous transmettez volontairement peuvent être utilisées pour traiter votre demande.

6. Absence de suivi publicitaire

Noki Noki n’utilise pas de cookies ni de tracking publicitaire dans cette version.

7. Partage des données

Noki Noki ne vend pas vos données personnelles. Les échanges avec les vendeurs ou acheteurs se font via WhatsApp, un service externe qui possède ses propres règles de confidentialité.

8. Suppression des données

Vous pouvez supprimer vos données locales :

  • En supprimant vos annonces directement dans l’application
  • En désinstallant l’application de votre appareil

Pour demander le retrait d’une annonce problématique, vous pouvez contacter le support.

9. Sécurité

Les données étant stockées localement sur votre appareil, leur sécurité dépend aussi de la protection de votre téléphone. Nous recommandons de ne jamais publier d’informations sensibles dans une annonce.

10. Contact

Pour toute question ou demande concernant vos données, vous pouvez nous contacter à :

Email : dev.mesapps@gmail.com

11. Évolution

Cette politique pourra évoluer avec les futures versions de Noki Noki, notamment si des fonctionnalités comme un serveur, un compte utilisateur ou un paiement réel sont ajoutées.
